How comparison works

Object properties are compared by key and arrays by position. Values and types are compared exactly. Large added or removed structures appear as one change; the visual report describes changes; a separate JSON Patch export generates RFC 6902 add/remove/replace operations.

Maximum file or editor input: 2 MiB per side. The comparison stops after 5,000 differences to protect your browser from oversized reports. Patch export refuses results exceeding 5,000 operations rather than creating a partial patch. The patch preview implements only RFC 6902 add/remove/replace operations and applies them on a separate copy; move/copy/test are deliberately unsupported.
